=======================================================
STATE MANAGEMENT FLOW
=======================================================

1. INITIALIZATION
   └─ GameScreen mounts
      ├─ useGameState hook initializes
      │  ├─ Loads stats from localStorage("qwizzle:stats")
      │  ├─ Calls selectPuzzle() → gets word item
      │  ├─ Calls newGame() from engine → GameState object
      │  └─ Sets initial state (rows, cursor, etc.)
      └─ useKeyboard hook sets up listener

2. USER INPUT → GAME STATE UPDATE
   ├─ User presses key
   ├─ useKeyboard listener triggers
   ├─ onChar/onBackspace/onEnter callback invoked
   ├─ State updates: rows, cursor
   ├─ Re-render: Board shows updates
   └─ If Enter pressed → validation flow starts

3. GUESS VALIDATION FLOW
   ├─ onEnter callback triggered
   ├─ Check length: rows[cursor].length === targetLength
   ├─ Check validity: provider.isValidGuess(guess, category)
   │  └─ LocalListProvider checks against acronyms/words array
   ├─ If invalid:
   │  ├─ Set message: "Not in list" | "Not enough letters"
   │  ├─ Set tone: "error"
   │  ├─ Flash invalidRow animation
   │  └─ Clear message after 3s
   └─ If valid:
      ├─ Call engine.submitGuess()
      ├─ Calculate feedback via computeFeedback()
      ├─ Update feedbackRows
      ├─ Update keyState (letter colors)
      ├─ Update cursor → next row
      ├─ Check game end: isWin || guesses >= maxGuesses
      ├─ If game over:
      │  ├─ Set gameOver = true
      │  ├─ updateStats(didWin)
      │  ├─ Create result object
      │  ├─ Show result modal
      │  └─ Trigger confetti if win
      └─ Animate current row

4. STATS UPDATE FLOW
   ├─ Game ends (win or max guesses reached)
   ├─ updateStats(didWin) called
   ├─ Calculate score increment:
   │  └─ efficiency * wordLength (only if win)
   ├─ Update stats object:
   │  ├─ played++
   │  ├─ wins += (didWin ? 1 : 0)
   │  ├─ streak = didWin ? streak + 1 : 0
   │  ├─ best = max(best, streak)
   │  └─ score += increment
   ├─ Persist to localStorage("qwizzle:stats")
   └─ Update UI display

5. THEME TOGGLE FLOW
   ├─ User clicks theme button
   ├─ useTheme().toggleTheme() called
   ├─ Theme state changes: "dark" ↔ "light"
   ├─ ThemeProvider sets html.dataset.theme
   ├─ CSS variables re-evaluate
   ├─ UI re-renders with new colors
   └─ Persist to localStorage("qwizzle:theme")

=======================================================
DAILY PUZZLE SEEDING
=======================================================

Algorithm: dailySeed() in apps/web/src/utils/dailySeed.ts

Input:
- category: "acronym" | "vocab"
- listLength: number (dataset length)

Process:
1. Get today's date: new Date().toISOString().split("T")[0]
   └─ Format: "YYYY-MM-DD"
2. Create key: `${category}-${date}`
   └─ Example: "acronym-2025-11-15"
3. Hash key using simple djb2 algorithm:
   ├─ Iterate each character
   ├─ hash = (hash << 5) - hash + charCode
   └─ Bitwise AND to 32-bit int
4. Return: Math.abs(hash) % listLength
   └─ Range: [0, listLength)

Result:
- Same category, same day → Same index every time
- Different day → Different index (new puzzle)
- Changes at midnight UTC

=======================================================
KEYBOARD INPUT HANDLING
=======================================================

useKeyboard Hook (apps/web/src/hooks/useKeyboard.ts):

1. Add window.keydown listener
2. For each keydown event:
   ├─ Check if target has data-keyboard-capture="true"
   │  └─ If yes: ignore (in text input)
   ├─ If key === "Enter":
   │  ├─ preventDefault()
   │  └─ Call onEnter()
   ├─ If key === "Backspace":
   │  ├─ preventDefault()
   │  └─ Call onBackspace()
   ├─ If key matches /^[A-Za-z]$/:
   │  └─ Call onKey(key.toUpperCase())
   └─ Else: ignored

GameScreen double protection:
├─ useKeyboard handles window events
└─ Hidden input#key-capture with onKeyDown handler
   ├─ Captures keyboard input
   ├─ Converts to uppercase
   ├─ Clears input value
   └─ Prevents unwanted characters

Modals disable capture:
├─ When showHelp || showStats || showResult:
│  └─ Keyboard capture disabled
│     └─ User can interact with modal content
└─ Otherwise:
   └─ Focus remains on key-capture input

=======================================================
ANIMATIONS & VISUAL FEEDBACK
=======================================================

Row Animation (animatingRow state):
- Triggered: After successful guess submission
- Duration: 600ms + (120ms * wordLength)
- Effect: Tile flip animation (CSS)
- Trigger: setAnimatingRow(cursor)
- Clear: setTimeout(() => setAnimatingRow(null), delay)

Invalid Row Shake (invalidRow state):
- Triggered: Validation failure (length, validity)
- Duration: 500ms
- Effect: Horizontal shake (CSS)
- Trigger: setInvalidRow(cursor)
- Clear: setTimeout(() => setInvalidRow(null), 500)

Confetti Effect (canvas-confetti):
- Triggered: Game win
- Three bursts:
  1. 240 particles, spread 95°, velocity 55
  2. 180 particles, spread 120°, velocity 45, decay 0.9
  3. 140 particles, spread 110°, velocity 60
- Origin: varies for visual effect

Message Display (message state):
- Auto-clear: setTimeout(() => clearMessage(), 3000)
- Types: success ("Nice!"), error, neutral
- aria-live="polite" for accessibility

=======================================================
ERROR HANDLING FLOW
=======================================================

Validation Errors (UI):
├─ Length mismatch:
│  └─ Message: "Not enough letters"
├─ Not in word list:
│  └─ Message: "Not in list"
└─ Handler: Show message, invalid row flash, auto-clear

Engine Errors (Game Logic):
├─ TARGET_REQUIRED: Missing puzzle target
├─ WRONG_LENGTH: Guess length mismatch
└─ EMPTY_WORD_LIST: No words in category

Error Boundary (React):
├─ Catches rendering errors
├─ Shows: "Something went wrong."
├─ Offers: "Reload" button
└─ Component: ErrorBoundary.tsx

localStorage Errors (Persistence):
├─ Safe to fail - game continues
├─ Fallback to defaults
├─ Console warning logged
└─ Storage.ts handles silently

=======================================================
SHARING FLOW
=======================================================

User clicks "Share" in result modal:
├─ Handler: handleShare() in GameScreen
├─ Build message:
│  └─ shareText("acronym", result.feedbackRows, solvedIn, url)
├─ Attempt native share:
│  ├─ If navigator.share:
│  │  └─ navigator.share({ text: message })
│  └─ On error:
│     └─ Fallback to clipboard
├─ Attempt clipboard:
│  ├─ If navigator.clipboard:
│  │  └─ navigator.clipboard.writeText(message)
│  └─ On error:
│     └─ Show "Unable to share. Copy manually."
└─ Show status: "Shared!" or "Copied to clipboard"

Share Message Format:
"Qwizzle acronym 3/6
🟩🟨⬛🟩🟩
⬛🟨🟩⬛🟩
🟩🟩🟩🟩🟩
https://qwizzle.local"

Shares:
├─ Mode (acronym/vocab)
├─ Solved in X/6 (or X/6 if lost)
├─ Emoji grid representing guesses
└─ Optional URL for sharing
